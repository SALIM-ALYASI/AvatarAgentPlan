خطة عمل (مرحلة 2): وكيل يحرك صورة + ملف صوت (Lip‑Sync) — مجاني 100% (SadTalker)
التاريخ: 2026-02-21
الهدف: تبني “وكيل” عنده زر/أمر واحد يأخذ (photo.jpg + voice.wav) ويُنتج فيديو (result.mp4) لوجه يتكلم (تحريك شفاه + تعابير بسيطة).

------------------------------------------------------------
0) النتيجة المتوقعة
------------------------------------------------------------
- إدخال:
  1) صورة ثابتة للشخص: photo.jpg أو photo.png (يفضل وجه واضح وإضاءة جيدة)
  2) ملف صوت: voice.wav أو voice.mp3 (يفضل WAV 16-bit, 22.05k أو 44.1k)
- إخراج:
  - فيديو MP4: outputs/result.mp4
- ملاحظة:
  - هذا الحل “Talking Head” (وجه/رأس). الجسم الكامل يحتاج مشروع مختلف (مرحلة لاحقة).

------------------------------------------------------------
1) تجهيز المشروع داخل agent-podcast
------------------------------------------------------------
أضف مجلد جديد داخل مشروعك (أو في أي مكان تحبه):
agent-podcast/
  avatar-agent/
    inputs/
      photo.jpg
      voice.wav
    outputs/
    sadtalker/            (سيتم تنزيله هنا)
    run_avatar.sh         (زر واحد للتشغيل)
    run_avatar.py         (اختياري: تشغيل عبر بايثون)

------------------------------------------------------------
2) المتطلبات
------------------------------------------------------------
- Git
- Conda (Miniforge/Anaconda) — موجود عندك غالبًا
- Python 3.9 (مناسب لساد توكر)
- ملاحظة عن Mac (Apple Silicon):
  - شغال، لكن أبطأ من NVIDIA.
  - نقدر لاحقًا نضيف “Upscale” للفيديو لتحسين الدقة.

------------------------------------------------------------
3) التثبيت (SadTalker) — مرة واحدة فقط
------------------------------------------------------------
داخل مجلد avatar-agent نفّذ:

1) تنزيل المشروع:
   git clone https://github.com/OpenTalker/SadTalker.git sadtalker

2) إنشاء بيئة:
   conda create -n avatar python=3.9 -y
   conda activate avatar

3) تثبيت المتطلبات:
   cd sadtalker
   pip install -r requirements.txt

4) (اختياري) لو واجهت مشاكل torch على Mac:
   - جرّب تثبيت torch المتوافق مع جهازك حسب إرشادات PyTorch الرسمية.

------------------------------------------------------------
4) اختبار سريع (تشغيل يدوي)
------------------------------------------------------------
افترض أن ملفات الإدخال موجودة هنا:
avatar-agent/inputs/photo.jpg
avatar-agent/inputs/voice.wav

شغّل (وأنت داخل sadtalker):
python inference.py   --driven_audio ../inputs/voice.wav   --source_image ../inputs/photo.jpg   --result_dir ../outputs

المخرجات ستظهر داخل:
avatar-agent/outputs/

------------------------------------------------------------
5) تحويله إلى “وكيل” بزر واحد (run_avatar.sh)
------------------------------------------------------------
الفكرة: أمر واحد يأخذ صورتك وصوتك ويطلع الفيديو.

ملف: avatar-agent/run_avatar.sh
- يتأكد من وجود conda env اسمها avatar
- يفعّلها
- يروح لمجلد sadtalker
- يشغل inference.py بباراميترات واضحة
- يطبع مسار الفيديو الناتج

أمثلة استخدام:
./run_avatar.sh inputs/photo.jpg inputs/voice.wav

------------------------------------------------------------
6) قواعد جودة الإدخال (عشان تطلع النتيجة حلوة)
------------------------------------------------------------
للصورة:
- وجه واضح، أمام الكاميرا، بدون ميلان قوي.
- إضاءة جيدة، بدون ظلال قوية على الفم.
- خلفية بسيطة أفضل.

للصوت:
- بدون ضجيج عالي.
- مستوى صوت ثابت (ما يكون منخفض جدًا).
- يفضل WAV بدل MP3 لو تقدر.

------------------------------------------------------------
7) تحسينات اختيارية (مرحلة 2.1)
------------------------------------------------------------
A) قص الصمت وتنظيف الصوت (قبل التحريك)
- تقدر تستخدم ffmpeg لإزالة صمت البداية والنهاية وتحسين الوضوح.

B) رفع دقة الفيديو (Upscale) — إذا تبغى قريب من 4K
- SadTalker غالبًا يخرج بدقة أقل.
- نرفع الدقة بعدها عبر:
  - ffmpeg upscale (سهل، لكن “تكبير عادي”)
  - أو Real-ESRGAN (أفضل جودة، لكنه أثقل)

C) دمج مع مشروعك الحالي (agent-podcast)
- بعد ما تولّد الصوت في tmp/reply.wav:
  - ترسله مباشرة إلى avatar-agent كـ driven_audio
  - وتطلع فيديو جاهز للعرض

------------------------------------------------------------
8) واجهة “وكيل” (مرحلة 2.2) — اختياري
------------------------------------------------------------
لو تبغى خدمة محلية:
- endpoint بسيط (Flask/FastAPI أو Node.js)
- يرفع صورة وصوت
- يرجع mp4

لكن كبداية: run_avatar.sh يكفي ويخلص.
